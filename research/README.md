# 研究与历史证据

本目录保存竞品实测、截图、网页流程图和当时的 Playseed 落地记录，用于追溯设计依据。

这些文件描述的是某次研究或某个历史版本，不代表当前产品已经实现的能力，也不作为后续 AI 的默认任务清单。当前信息统一从 [项目文档中心](../docs/README.md) 读取。

使用研究资料时，先区分三类内容：

- **可见事实**：截图、页面文字、真实操作结果。
- **当时判断**：基于事实提出的产品分析。
- **历史落地**：某个旧版本做过的改变，可能已被后续版本替代。

新的竞品研究应保存日期、产品版本或页面状态，并在当前路线发生变化时单独更新 `docs/`，不要直接把竞品流程当成 Playseed 的产品定义。
