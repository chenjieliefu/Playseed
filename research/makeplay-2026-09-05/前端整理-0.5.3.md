# Playseed 0.5.3 前端整理

以已保存的 MakePlay 实测截图 S001、S002、S005、S014、S018 为依据。保留 Playseed 自己的配色、吉祥物和项目栏。

| MakePlay 实测交互 | Playseed 对应实现 |
|---|---|
| 首页单一输入，作品入口放在下方 | 输入想法 → 开始创作；最近项目改为带真实预览的卡片 |
| 顶部项目工具栏，左对话右预览 | 项目标题移到顶部，项目栏可以折叠；中间对话、右边预览 |
| 完整方案按需打开 | 对话方案卡和顶部“游戏方案”打开弹层，关闭返回原画面 |
| 继续修改仍使用原输入框 | 一个固定底部输入框；默认直接修改，纯讨论移入“更多” |
| 生成中 STOP，完成后 SEND | 发送和停止占用同一位置，状态和可展开过程显示在输入框上方 |
| 修改期间保留旧预览 | 右侧持续展示现有版本，查看方案、历史、清单通过弹层完成 |
| 工具不挤占主要工作区 | 历史恢复、制作清单放入“更多”；实验区与原有导出入口保留 |

选项进入聊天滚动区，每个问题带完整文本，选择多个问题的答案可以合并发送，同一问题重选会替换旧选项。

范围：仅整理前端布局与操作入口。右侧仍是明确标注的开场截图，“打开试玩”启动独立隔离窗口；没有把截图当作实时游戏，也没有加入尚未实现的发布、素材或设备模拟按钮。

验证：Godot 原生 UI 流程测试、输入焦点回归通过；渲染检查包含首页、等待、已有游戏、版本历史、1100×760 小窗口及方案弹层。截图位于 .playseed/qa/ux-*.png。未调用 AI 制作新游戏，已有对话、游戏和版本保留。
