# 侧栏与保存位置 · 0.5.4

按用户提供的 Tesana 展开/收起截图整理侧栏：品牌、创作主页（房子）、新建游戏（加号）、已有项目（游戏图标）。收缩控制位于侧栏内，收起后保留图标导航，悬停显示名称，点击展开并进入相应页面；偏好保存到本地。

试玩体验区从侧栏、菜单和项目列表中移除，旧文件没有删除。

保存位置入口位于侧栏底部、首页路径行、工作台更多菜单。系统文件夹选择器选择父目录，后台在其中创建“Playseed游戏”。先复制完整版本，再提交存储设置，原文件保留为备份。所有新游戏、预览、试玩和版本恢复通过统一存储路径读取。界面明确说明对话方案仍保存在 Playseed 本机项目目录。

验证：26 项 Python 测试通过（包含迁移后读取及恢复、复制失败、取消、冲突目录、不合法嵌套路径、外置目录缺失）；原生 UI 流程测试通过，包含侧栏收起保留图标、点击展开、移除实验区、目录选择信号进入后台请求。渲染检查覆盖展开、收起、保存位置弹层与小窗口。
