# 帧动画使用与验收

## 支持范围

规则网格PNG帧图，按从左到右、从上到下排序。行列各1至16，起始格从1开始，连续播放2至128帧，每秒1至30帧，可循环或单次播放。图片必须能均分，单帧至少4×4像素。

可选“对齐底部”：按半透明度不低于50%的主体像素确定底边，仅纵向移动整帧。为保留低透明度尾部像素，所有帧统一增加必要的透明画布高度；不裁切、拉伸或覆盖原PNG。适合站立、摆动，不适合保留高度变化的跳跃、飞行动作，默认关闭。全半透明图回退到非透明边界。它不识别真实脚底，不能消除角色轮廓、土堆形状等帧间变化。

不自动识别不规则角色拼图、不生成骨骼，也不把一张静态角色图称为真实行走帧。

## 用户路径

1. 在项目素材区导入规则帧图，确认方案后点击“切图与帧动画”。
2. 左边检查网格，右边看播放结果。可以切换深底、浅底、绿底检查透明残边，底色不写入图片或游戏。设置列数、行数、起始格、帧数、速度、循环与可选底部对齐；暂停后用上一帧/下一帧检查。
3. 保存只记录设置，不修改原PNG和当前游戏。动画区展示已配置帧动画，仍可重新设置或取消。
4. 通过“添加到对话”说明用途并发送，制作出新游戏版本后试玩验收。

也可在聊天输入：`设置动画：「素材名」，4列，1行，从1格开始，4帧，每秒8帧，循环`。支持“不循环”，可追加“，底部对齐”或“，保留原位”；不指定时保留既有对齐设置。同名素材时使用素材编号。该格式是确定性设置入口，不是任意自然语言自动理解。

## 验收

- 左右与换行顺序正确，无越界切图、拉伸或相邻帧渗入。
- 每帧主体完整、基线与尺寸一致，播放无意外位置跳动；生成帧图不一致时不能宣布动画素材合格。
- 循环、单次结束、暂停、逐帧和重开正确；游戏中的停止/重开不能遗留动作进度。
- 保存、取消配置不会更改原图与旧游戏版本。新游戏保存独立动画配置快照，恢复旧版不能读到新的库配置。

## 实现与证据

- `sprite_assets.py`：参数、项目、方案版本、图片哈希及取消校验；配置与素材清单原子保存。
- `app/sprite_editor.gd`：切图与播放审阅；`app/asset_animation_preview.gd`：动画列表预览。
- `runtime/playseed_sprite_frames.gd`：创建实际AtlasTexture和SpriteFrames，供编辑器与游戏共用；`asset_animation(id)`供制作模型调用。
- `resources.prepare_runtime`：保存`assets/animations.json`到游戏版本；恢复从旧版本读取，不从当前素材库重算。
- 84项Python检查通过；Godot帧顺序/单次结束/暂停/重开专项通过，创作界面及输入回归通过。界面检查包括逐帧、无效网格禁止保存、窗口高度及提交参数。既有UI测试退出资源释放警告仍在。
- 证据：`.playseed/qa/sprite-frames/`。真实制作与专项试玩结果在开发执行记录追加，不以固定测试代替真实生成验收。

API依据：[Godot SpriteFrames](https://docs.godotengine.org/en/stable/classes/class_spriteframes.html)、[AtlasTexture](https://docs.godotengine.org/en/stable/classes/class_atlastexture.html)。以本机Godot运行验证为准。

真实花园已完成第3版接入、第4版加速、第5版恢复；三个版本都按对应速度通过专项试玩。第5版代码、帧图和动画配置与第3版完全相同。记录见[开发执行记录](09-开发执行记录.md)。

底部对齐专项证据：`.playseed/qa/sprite-alignment/`。首轮采用所有非透明像素定位，真实样本残余淡像素导致视觉偏差，已否决；现按可见主体定位，测试保留低透明度像素总量、源图不变，真实四帧底边从569/572/543/547对齐到572。对齐不等于素材整体艺术质量达标。
