# 素材质量标准

适用版本：0.8.24。用于单张2D角色、道具和场景图片的准备与审阅；不代表已完成动画或3D生产线。

## 采用前检查

| 项目 | 合格要求 | 检查方式 |
|---|---|---|
| 文件有效 | 可解码、尺寸有效、有可见内容 | 自动检查，空图拒绝 |
| 透明背景 | 独立角色、道具按用途具备真实透明像素，棋盘格不能画入图片 | 自动检测透明像素；修复稿不透明时拒绝采用 |
| 边缘 | 深色和浅色背景下，无明显白色轮廓、夹缝残底或明显缺口 | 切换底色并放大人工检查 |
| 主体 | 数量、轮廓、肢体、内部细节、必要半透明区域符合方案 | 与原稿对照，不以透明检查代替完整性检查 |
| 风格和用途 | 色彩、纹理、比例适合项目；背景和独立道具用途区分清楚 | 按方案和参考图片审阅 |
| 来源与保护 | 原稿保留、处理独立成稿，采用记录来源和参数 | 后端校验；采用不直接更改游戏版本 |

只有透明像素不等于质量合格。白色主体、细毛、复杂重叠对象必须逐张检查，不自动宣称通过。游戏入场后的遮挡、缩放和交互另外按游戏验收执行。

## 处理方式

本机去背景默认不收边、不清理浅色残边。已透明图片在这两个默认条件下原文件逐字节保留；明确选择调整时使用原透明蒙版，避免重复分割。对不透明图片使用系统主体分离。

“清理浅色残边”是显式可选项，只在蒙版边界附近12个原图像素内处理近中性的浅色残留。它是启发式方法，可能削减白色轮廓或毛发，并非通用精细抠图。先小幅收边，切换深浅底和原稿对照；不合格则放弃处理稿、调整选项或换用用户提供的透明素材。不会自动循环调用付费图片工具。

## 0.8.24细节保护

浅色候选像素还必须与蒙版外边缘连通才会被清理，避免删除主体内部不相连的白色高光。

清理后逐个比较连通区域的透明度加权面积：区域至少相当于64个不透明像素、且损失超过15%时，中止保存并提示关闭“清理浅色残边”重试。不会生成可采用的受损稿，也不自动切换付费模型。该阈值用于拦截明显误删，不是精细结构完整性的证明；微小部件、低于阈值的损伤和收边本身造成的损失仍需人工检查。

新增固定像素样本覆盖全白主体、较大彩色主体旁独立的小白色主体、半透明细线与白色交叉区域：危险清理均被拦截，关闭清理后原文件完全保留。真实蘑菇重新处理成功并检查主体与边缘。78项Python检查通过。本轮没有进行复杂真实毛发的分割质量验证，不将合成像素样本当作真实毛发验收。

证据在`.playseed/qa/material-protection/`。下一步补真实白色角色与复杂毛发样本的人工验收，再开始动画帧与切图；不得跳过来源、采用和游戏入场检查。

### 真实白色长毛样本失败记录

2026-09-06固定白色长毛猫：生成稿虽有alpha但带雾状残底；一次编辑返回不透明棋盘格；本机分离得到透明稿但截掉胡须、毛尖。判定未通过，不采用、不进入游戏。证据`.playseed/qa/white-fur/`。已透明输入默认保持原稿只能避免二次损伤，不能自动清除原稿的雾底。后续动画验证只使用已合格素材，不代表此问题解决。

## 静态模型草稿审阅（0.8.34）

基础形状道具另检查正背面轮廓、部件数量与连接、颜色、悬空、共面黑缝和缩放后辨识度。自动检查只验证文件、保守的部件包围盒连接与游戏运行，不能替代曲面接触、美观或需求匹配的审阅。生成失败不入库；造型不合格先放弃或改描述重做，不为了证明制作成功而采用。

Blender源文件和生成描述随草稿保留，采用后GLB按游戏版本保存。贴图、骨骼、精细人物、曲面布尔与授权自动审核尚未接通。
