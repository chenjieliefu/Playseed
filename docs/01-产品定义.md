# Playseed 产品定义

## 一句话定位

Playseed 是一个对话式 AI 游戏创作平台：普通人说出想法，平台帮助他理清方案、准备素材、制作可玩的版本，并在试玩后继续修改。

愿景：**让制作游戏变得简单，让每个人都有自己的游戏。**

## 为谁解决什么问题

核心用户是不懂编程、Godot、场景节点和美术制作的人。他可能只有一个角色、一种感觉或一个模糊场景。Playseed 要承担从模糊想法到明确玩法、从明确玩法到可玩工程的转换工作。

用户需要理解自己的游戏，不需要理解内部技术。界面应该围绕以下几个问题组织：

1. 我想做什么？
2. 第一版具体玩什么？
3. 还缺哪些角色、场景或声音？
4. 现在做到哪一步？
5. 做出来以后哪里需要改？

## 产品成功的标准

- 用户原本的角色、世界、目标和感受得到保留。
- 模糊想法能通过少量问题变成可以确认的第一版方案。
- 明确方案能稳定生成一个完整可玩的版本。
- 用户可以用自然语言连续修改，并能恢复以前的版本。
- 失败时不会丢失想法、素材或最近一个可玩版本。
- 生成的游戏在玩法、画面和反馈上逐步丰富，而不是所有需求都套用同一个模板。

## 产品原则

- **对话是主流程。** 用户在一个聊天框内完成构思、确认、制作和修改；右侧工具用于查看和补充。
- **先小而完整。** 第一版先形成能开始、能操作、有目标、有结束和能重来的完整体验，再逐步增加内容。
- **状态必须真实。** “方案已确认”“素材已准备”“检查已通过”“可以试玩”分别表示不同事实。
- **保留用户决定。** AI 的建议和暂定项要明确标注，不能改写用户的核心想法。
- **类型不是白名单。** 射击、经营、解谜等只是验证样本；平台目标是逐步支持更多类型。
- **诚实说明边界。** 当前以小型2D游戏为主，基础WAV声音已接通；另开放实验性3D房间寻物。复杂3D、联网和公开发布仍需按路线图推进。
- **Playseed 是自己的产品。** 品牌、交互、创作流程和产品判断由 Playseed 定义；Godot 是底层游戏运行引擎。

## 当前产品形态

0.8.37 是 macOS 本机原型。用户使用本机登录的 GPT 账号，项目保存在自己选择的文件夹。平台已经验证“想法 → 方案 → 制作清单 → 生成 Godot 游戏 → 检查 → 试玩 → 修改 → 版本恢复”这一条主链路。

当前目标不是制作一款内容庞大的示例游戏，而是提高不同想法第一次做成和连续修改成功的概率。
