## 当前验证说明

Python 自动测试当前共 127 项，覆盖方案、模型参数、生成、失败保护、版本、素材、存储、项目操作和 P0 验收矩阵。Godot 侧另有创作界面、游戏和输入回归测试。

2026-09-06 重跑结果：此前 38 项 Python 测试和三组 Godot 测试均通过；本轮新增旧操作回归隔离测试后，39 项 Python 测试全部通过。`creator_tests.gd` 在退出测试进程时仍会打印 Godot 资源未释放警告；警告出现在通过信息之后且进程返回成功，目前记录为测试清理问题，后续仍需消除。

0.8.4 将首页、工作台和素材区的文件选择全部交给 macOS 原生文件窗口，避免 Godot 内嵌文件窗口出现黑屏；首页附件入口精简为单独的“＋”，左下角 GPT 账号入口使用 Playseed 农夫吉祥物。

0.8.5 清理首页输入框底栏：将状态提示移到控制行上方，并把模型、强度和发送按钮重新对齐。

0.8.6 修正首页附件入口：恢复固定圆形底板，将“＋”在底板内水平、垂直居中，并取消悬停后出现在输入框下方的灰色提示条。附件菜单和原生文件选择功能保持可用。

启动窗口按当前屏幕可用区域的 90% 居中显示，保留手动缩放。原生标题使用“Playseed · AI 游戏创作”，隐藏内置编辑器运行组件附加的 DEBUG 字样；并未关闭诊断或变成正式发布构建。

五个验收游戏可从仓库根目录的 `验收游戏/` 文件夹双击中文 `.command` 入口试玩，并查看对应预览图和版本说明。默认入口打开当前最新版；带“最初版本”的入口打开第 1 版，不覆盖当前版本。入口通过 `scripts/play_validation.py` 重跑检查，再使用与产品相同的隔离进程打开。原始工程仍保存在 `.playseed/validation/`，不会混入正式项目栏。

P0 已建立五类固定验收方案：平台跳跃、俯视射击、经营、解谜和塔防。每类都包含第一版范围与三轮连续修改任务；真实运行会写入独立验收目录，不进入用户项目列表。可先用 `scripts/validate_creation.py --genre platformer` 单独验证一种玩法，再用 `--with-revisions` 执行三轮连续修改。

2026-09-06 使用 GPT-5.6 Sol、中等强度运行五类第一版验收，5/5 最终通过。俯视射击、经营、解谜和塔防一次通过；平台跳跃初稿被检查发现重开后输入状态未恢复，经过一次自动修复后通过。五类最终版本均通过静态限制、Godot 解析、120 帧启动、真实核心操作状态变化和重开恢复，并各自生成了预览图。这证明五类第一版可以在本次样本中做出来；随后五类各完成三轮真实修改，15/15 通过本次运行检查，均未触发自动修复。每轮重跑早先版本的操作探针，旧版本文件哈希保持不变。

历史上实际用模型生成并试玩过射击、经营和解谜三个小型 2D 项目，也验证过射击从单发改成双发以及版本恢复。这些结果证明主链路可以工作，不代表所有同类游戏都能稳定生成。

## 不能混淆的几个概念

- “GPT 返回了代码”不等于“游戏能运行”。
- “Godot 检查通过”不等于“游戏好玩或好看”。
- “工具里能预览动画或特效”不等于“已经加入当前游戏”。
- “底层 Godot 支持 3D”不等于“Playseed 已能自动制作 3D”。
- “记录了自动设计素材”不等于“已经生成并使用素材”。

## 三轮修改专项验收与交接

本轮使用 `scripts/validate_revisions.py` 延续五个第一版工程，每个保存至第 4 版。`scripts/check_validation_semantics.py` 与 `scripts/validation_checks/` 对第 2、3、4 版分别执行固定状态的实际玩法检查，共 15 份报告全部通过：

- 平台跳跃：二段跳上限、移动平台位移、收集开门和重开。
- 射击：双弹运动、每四次击杀加速、护盾免伤与冷却、失败和重开。
- 经营：急性子耐心、制作与收益、两级升级、连续服务奖励与中断。
- 解谜：提示不代操作、最短解穷举、不同步数评价和重开。
- 塔防：三种植物、实际弹丸命中与减速、快速敌人、出售返款且不能重复退款。

这些开发检查会设置位置、资源或敌人状态以直接验证规则，不是五款游戏从开局到结局的完整通关，也尚未接入产品通用验收门槛。报告分别位于 `.playseed/validation/20260906-174513/` 和 `20260906-175037/` 下的 `revision-reports/`、`semantic-reports/`。

第 4 版开场预览发现经营顾客信息与柜台交叠、解谜左灯标签与旅人提示交叠，已通过正常模型修改生成各自第 5 版修正，并核对三位顾客同时出现时的布局。塔防右键出售提示在开场提示结束后出现，属于原先预览观察遗漏，本轮未修改塔防。
